# Templates

Copy these into your own notes. They are the book's review and evidence formats, with nothing filled in.

## Review record (Chapter 8)

```
Output:            [what was produced]
Audience:          [who will read or act on it]
Data:              [sources; any restricted data?]
Allowed actions:   [read / draft / send / apply]
Review level:      [skim | full read | second reviewer + approval]
Evidence checked:  [what you opened, ran or compared]
Problem found:     [or "none"]
Correction:        [what changed]
Decision:          [approve | approve after correction | reject]
Reviewer and date: [name, date]
```

## Evidence card (Chapter 24)

```
Claim:                  [one exact statement, no broad words]
Period and scope:       [dates, environments, exclusions]
Source:                 [approved log, report or record]
Method:                 [how the count or time was measured]
Human effort:           [preparation, review, correction, maintenance]
Limitations:            [missing evidence, estimates, untested cases]
Publication permission: [what may be shared, confirmed by whom]
```

## Measured-value row (Chapter 14)

Use `data/worksheet.csv`, or:

```
Task | Before (min) | After: brief + operate | After: review + correct + check | Runs/month | Maintenance (min/month) | Saved = (Before − After) × Runs − Maintenance | Tool cost | Hourly value | Net = Saved/60 × Hourly − Tool | Keep?
```

## Tooling disclosure (Chapter 8, one page)

```
Approved tools:            [names, plan types]
Data each tool may see:    [categories; what is excluded]
Where data is processed:   [region, retention, training use: yes/no]
Actions needing a person:  [send, merge, deploy, delete, pay, change permissions]
Who decides exceptions:    [role]
Reviewed on:               [date]; next review [date]
```

## Publishing checklist (for the author)

- [ ] All companion commands run on a clean machine without the author's account
- [ ] Vendor privacy and product descriptions rechecked against Appendix D's links within the last month
- [ ] Figures and tables match the text where the same numbers appear
- [ ] Companion release tagged to match the edition
